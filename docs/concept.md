# お種帳（Otanecho）コンセプト

最終更新: 2026-09-20

## 一言で

「思いついた瞬間に 1 秒で書き留め、あとからオンデバイス AI で育てる」アイデア帳。

## 判断基準（迷ったらここに戻る）

1. **キャプチャの速さを最優先**。入力画面に到達するまでのタップ数と時間を増やす変更はしない。
2. **AI は黙って裏方**。使わなくても困らないが、使うと嬉しい位置に置く。入力を邪魔する提案・ポップアップは出さない。
3. **本文はユーザーのもの**。AI は本文を書き換えない。タイトル・タグ・問いだけを生成する。
4. **非対応端末でも完全に成立**。Foundation Models が使えない環境では AI 部分を静かに非表示にする。
5. **課金導線は入力動線に置かない**。深掘りの終わりと週次レビューの末尾だけ。

## 市場から見た空白地帯

| グループ | 代表 | 強み | 弱み |
|---|---|---|---|
| 高速キャプチャ | Drafts, Simple Memo, Apple Notes | 起動 0.4〜1.7 秒 | AI なし。書いた後に育てる導線がない |
| 書き溜め + 振り返り | flomo | カード式、毎日レビュー | AI が弱い、クラウド必須 |
| AI 音声メモ | Nemos, AudioPen, Voicenotes | 話すだけで整形 | 全文がクラウドへ、月 $8〜10 |
| 知識管理 | Notion, Capacities, mymind | 整理・連結 | モバイル入力が遅い |

「高速キャプチャ」と「AI で育てる」を両立し、かつオンデバイスで完結するアプリは存在しない。Foundation Models は AI の原価がゼロなので、競合より安く、プライベートに提供できる。

## コア体験

- **種をまく**: アクションボタン、コントロールセンター、ロック画面、ホーム画面ウィジェット、共有シート、Siri、音声のどこからでも入力画面に直行。保存ボタンはない。
- **裏方の AI**: 保存直後にタイトルとタグを付け、詳細画面で関連する種を提示する。
- **芽を出す**: 「この前提は本当?」「一番困っているのは誰?」など問いを 3 つ返す。答えるほど 種 → 芽 → 木 に育つ。
- **今週のふりかえり**: 放置された種を再浮上させ、意外な組み合わせを提案する。

## 成長段階

| 段階 | 条件 |
|---|---|
| 種 | 深掘りへの回答 0 |
| 芽 | 回答 1〜2 |
| 木 | 回答 3 以上 |

## ビジネスモデル（MVP の次のマイルストーン）

| 区分 | 内容 | 価格案 |
|---|---|---|
| 無料 | キャプチャ全機能、メモ数無制限、AI タグ付け、深掘り 1 日 3 回 | ¥0 |
| Pro | 深掘り無制限、Private Cloud Compute の高性能モデル、週次 AI レビュー、iCloud 同期、エクスポート、テーマ、iPad/Mac | ¥480/月、¥2,800/年 |
| 買い切り | Pro 永久 | ¥9,800 |

- 原価構造: オンデバイス推論と Private Cloud Compute（Small Business Program 対象）は無料、同期は CloudKit。
- ハードペイウォールは採用しない（使いやすさ優先）。

## 技術方針

- iOS 26.0 以上、SwiftUI + SwiftData（App Group 共有ストア）、Swift 6（default MainActor isolation）。
- Foundation Models: `@Generable` で構造化出力、候補は番号で渡して UUID は生成させない、on-device の 4K コンテキストを前提に入力を切り詰める。
- iOS 27 専用 API（Vision 入力、Private Cloud Compute）は `#available` で段階的に導入する。
- XcodeGen で `project.yml` からプロジェクトを生成。`Otanecho.xcodeproj` は Git 管理外。

## MVP の範囲

1. 高速キャプチャ（アプリ内、アクションボタン、コントロールセンター、ロック画面/ホーム画面ウィジェット、共有拡張、Siri、音声）
2. タイムライン・検索・詳細編集
3. AI タグ付け・タイトル生成・関連する種
4. 芽を出す（深掘り 3 問）
5. 今週のふりかえり

課金、iCloud 同期、iPad/Mac 最適化、String Catalog による多言語化は MVP の次。
